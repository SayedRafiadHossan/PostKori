# PostKori — ছবি দিন, পোস্ট নিন

AI tool for Bangladeshi Facebook (f-commerce) sellers. Upload a product photo and get a
product description, Facebook caption, hashtags and a price post — in Bangla and English.

## Tech stack
- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Google Gemini (from Step 3)

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000
